- Dataset: 12 *invented, embedded* example sentences; training repeats to **36** sequences. No FineWeb was downloaded. This is an isolated harness correctness demonstration, **not** corpus-scale language-model training.
- Shape test: `(B,T)=(2,20)`, `(B,T,D)=(2,20,48)`, `(B,T,V)=(2,20,128)`. The notebook prints 20 more intermediate shapes and a string-level token alignment table.

There is no theorem that masking makes CE larger or smaller: the before/after value depends on the discarded target's loss relative to the mean.

## Design and evidence notes

- A causal mask protects against future leakage. A **document-blocking attention mask** and resetting learned positional indices protect packed examples; masking only EOS→BOS loss is insufficient.
- Cross entropy accepts **raw logits**. Do not softmax logits before passing them to `F.cross_entropy`.
- The objective excludes `<pad>` from the **target** (not valid EOS). We explicitly verify target counts and loss equivalence.
- Chunked loss mathematically matches full loss including an uneven last chunk, and gradients match within floating-point tolerance. For a real transformer, output-head-only chunking does not eliminate memory from upstream activations.
- Multi-token head at index *j* predicts *j+2* from the **same prefix** as head 1 at *j*. It cannot use the ground-truth token at *j+1*.
- The toy experiment contains no validation split; declining training loss is not evidence of robust predictive performance.
- CPU/GPU numerical results and memory consumption can vary by PyTorch version, machine, allocator and kernels. Seeded sampling plus explicit test tolerances establishes checks; it does not imply bitwise identity on arbitrary hardware.
