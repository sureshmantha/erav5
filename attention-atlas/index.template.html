What the date order reveals

There was never one universal winner. Sparse patterns tackled N², MQA/GQA/MLA tackled cache bandwidth, FlashAttention tackled IO without approximating softmax, then dynamic sparsity attacked compute again. Long context length alone is not proof of long-context recall.

Three easy-to-miss distinctionsKV-cache storage grows linearly with context, while dense attention work grows approximately quadratically. FlashAttention is exact, not linear attention. Top-k token sampling is unrelated to top-k attention selection.
